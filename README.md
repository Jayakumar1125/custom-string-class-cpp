# Custom String Class in C++

A simple implementation of a custom `Mystring` class in C++ using dynamic memory allocation.

## Features

- Default constructor
- Parameterized constructor
- Copy constructor
- Copy assignment operator
- Move constructor
- Move assignment operator
- Character access using `[]`
- String concatenation using `+`
- String comparison using `==` and `!=`
- Custom string length function
- Input and output operators
- Destructor for memory management
